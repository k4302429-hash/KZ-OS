# KZ OS — Preview interativo

O diretório `preview/` contém um protótipo web interativo para experimentar a interface no navegador. Ele simula o desktop e os aplicativos; não é o aplicativo Android nem virtualiza hardware.

Para testar localmente, abra `preview/index.html` em um navegador moderno. Preferências, notas e arquivos de demonstração são guardados no armazenamento local do navegador.
